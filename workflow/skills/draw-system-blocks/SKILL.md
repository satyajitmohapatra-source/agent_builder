# Draw System Blocks

Create a Mermaid block or flowchart diagram. Show the user, agent, conversation host, runtime skills, tools, and storage only where relevant. Label the owner of each operation and the direction of calls and results. Mark interfaces that are proposed, verified, or pending. At intake, show the boundaries implied by the PRD and name what remains unknown.

Apply this skill at intake, architecture drafting, each layer review, generation planning, implementation, verification, and handoff. Update the project's visual review record and surface the relevant view in the conversation before asking the engineer to decide. Use the current PRD, approved decisions, pinned SDK, and evidence for the stage. Label gaps explicitly.

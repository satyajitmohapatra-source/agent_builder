# Draw Conversation Flow

Use a Mermaid sequence diagram with lanes for the user, client, host, agent, and affected tools or stores. Show the user’s words or a redacted example, response ownership, clarification or interruption, and a meaningful alternate path. In the same diagram show database reads and writes where applicable, with their owners. Label examples as proposed. For observed sessions, use the Observe Conversation Flow skill and cite trace or receipt evidence.

Apply this skill at intake, architecture drafting, each layer review, generation planning, implementation, verification, and handoff. Update the project's visual review record and surface the relevant view in the conversation before asking the engineer to decide. Use the current PRD, approved decisions, pinned SDK, and evidence for the stage. Label gaps explicitly.

# Draw LangGraph Flow

Show entry, nodes, conditional edges, relevant state reads and writes, and exit. Show pause, resume, and checkpoint paths when applicable. If LangGraph is proposed, label the diagram as a candidate and show any decision needed to choose it. If a different runtime is selected, show its actual control flow and mark LangGraph as not selected. Use the graph definition for implemented paths and execution evidence for observed paths.

Apply this skill at intake, architecture drafting, each layer review, generation planning, implementation, verification, and handoff. Update the project's visual review record and surface the relevant view in the conversation before asking the engineer to decide. Use the current PRD, approved decisions, pinned SDK, and evidence for the stage. Label gaps explicitly.
